# Агент фактов о породах на LangChain

Консольный агент отвечает на вопросы о породах кошек и собак. Наружу он отдаёт список фактов: каждое предложение с новой строки, с мордочкой кошки или собаки.

Тема сидит в промпте и в инструментах. Цикл «вопрос → решение модели → инструмент → строгий список» делает LangChain.

## Структура

```
LANGCH/
  main.py            программа: агент, инструменты, диалог
  requirements.txt   пакеты для pip
  .env.example       образец ключа и адреса ProxyAPI
  .gitignore         локальные файлы не попадают в git
```

| Файл | Роль |
|---|---|
| `main.py` | единственная программа урока |
| `requirements.txt` | `langchain`, `langchain-openai`, `python-dotenv`, рабочая версия `tiktoken` |
| `.env` | ваш ключ; в git не коммитится |
| `venv/` | отдельный Python проекта; в git не коммитится |

## Где здесь LangChain

LangChain не хранит факты и не печатает мордочки. Он связывает модель, промпт и инструменты в один цикл.

1. `init_chat_model` создаёт модель `openai:gpt-4o-mini` и направляет её на ProxyAPI.
2. `@tool` описывает функции `get_cat_fact` и `get_dog_fact`: имя, аргумент `breed` и текст docstring. Это видит модель.
3. `create_agent` собирает цикл. Модель читает вопрос и промпт, сама выбирает инструмент и получает его текст обратно.
4. `ResponseFormat` и `ToolStrategy` заставляют финальный ответ быть списком строк `facts`, а не свободным абзацем.
5. `InMemorySaver` хранит историю. Ключ истории — `thread_id`, в этой программе он равен номеру пользователя.

Обычный Python вокруг этого: чтение `.env`, ввод с клавиатуры, карточки двух окрасов кошек в словаре `FACTS`, разбиение ответа на строки и значки 🐱 и 🐶.

Смена темы делается в промпте и в инструментах. Память, формат списка и номер пользователя от темы не зависят.

## Требования

- Python 3.10+
- ключ [ProxyAPI](https://proxyapi.ru/)

## Установка

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy .env.example .env
```

В `.env` впишите ключ ProxyAPI в `OPENAI_API_KEY`. Адрес уже указан: `https://api.proxyapi.ru/v1`. Имя модели задано в `main.py`: `openai:gpt-4o-mini`.

Пакет в `pip` пишется через дефис (`langchain-openai`), в коде импортируется через подчёркивание (`langchain_openai`). `tiktoken==0.12.0` зафиксирован, потому что более новая сборка на этой машине блокируется политикой приложений Windows и без неё `langchain_openai` не импортируется.

## Запуск

В активированном окружении:

```powershell
$env:PYTHONUTF8 = "1"
python main.py
```

`PYTHONUTF8` нужен, чтобы русский текст и мордочки в консоли Windows не превращались в кракозябры.

Программа спрашивает номер пользователя. Дальше пишите вопросы после `Вы:`. Пустая строка или «выход» завершают диалог. Программа сама не ждёт бесконечно и не является сервером: она заканчивается, когда вы выходите.

Чтобы говорить от другого человека, запустите `python main.py` снова и введите другой номер. У каждого номера своя история. Пока память хранится в `InMemorySaver`, она живёт только до закрытия программы.
